# f1-pole-position-for-what
Análise de dados sobre relevância da pole position na fórmula 1 (1950-2024)
# De que vale uma Pole Position?

Análise de 74 anos de Fórmula 1 (1950-2024), investigando se largar 
em pole position garante a vitória.

## Principais achados
- Apenas 43% das poles resultam em vitória
- A previsibilidade aumentou de 28% (anos 80) para 52% (anos 2020)
- Circuitos como Barcelona têm 70% de aproveitamento do pole, 
enquanto Jacarepaguá teve apenas 10%

## Ferramentas usadas
Python, pandas, matplotlib, Google Colab

## Fonte dos dados
[Formula 1 World Championship (1950-2024) - Kaggle](https://www.kaggle.com/datasets/rohanrao/formula-1-world-championship-1950-2020)
